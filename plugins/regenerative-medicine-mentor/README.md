# Regenerative Medicine Mentor

An educational and creative assistant by Professor Austin, adapted from the Regenerative Medicine Mentor GPT for the UCLA class on regenerative medicine and reproductive technology.

## What you can do

- Work through a scientific concept with a focused explanation and an example.
- Explore ethical questions about stem cells, reproductive technology, cloning, artificial wombs, and de-extinction.
- Develop a project idea or presentation argument using evidence and counterarguments.
- Practice with one multiple-choice question at a time after providing the relevant course material.

## Get started

Install the plugin, start a new task, select **Regenerative Medicine Mentor**, and try one of these prompts:

- Help me prepare for a quiz.
- Help me develop a regenerative medicine project idea.
- Help me explore the ethics of reproductive technology.

## Course materials

Quiz preparation first asks which professor's content you need. The plugin then checks the name and uses the matching supplied material. This bundle includes the instructor's configuration and topic brief; it does not include the original GPT Knowledge files, lecture files, assessments, or answer keys. You can provide your course notes in the conversation for focused study help.

The original instructor responses are preserved, including the distinction between Dolly as a nuclear clone and a completely identical genetic copy. Office hours and end-of-quarter responses describe the original course context; consult the current course announcements for later offerings.

## How it runs

This is a skills-only plugin. It adds no MCP server, external account connection, API key requirement, executable code, or publisher-operated data collection service. The host handles conversations and any files you provide under its own settings. When available, the host's research tools can check current scientific claims.

The mentor declines student requests for its raw setup. Distributed plugin files remain readable by recipients; this behavior does not encrypt or conceal the files.
